最新版は [最新のリリース](https://github.com/aquariumyossy/LexCrew-Mail/releases/latest) から入手できます。

Outlook クラシック（デスクトップ版）のメール画面で、ローカル LLM を使って返信の下書きや文面の推敲を行う Windows アプリです。作業ウィンドウに指示を書くと、開いているメールを読んで文面を整えます。メールの送信はしません。本文に入るのは、署名と引用の上に差し込む前文だけです。宛先と件名は、確認してから変えます。

## この版の変更

- **届いたメールの中の指示は、こちらの指示になりません** — 受け取ったメールに「宛先を変えろ」「この文を書け」と書いてあっても、それは作業ウィンドウの指示にはなりません。宛先と件名は、画面で中身を確認して「適用」を押したときだけ変わります。下書きの前文は、作業ウィンドウで出した指示に沿って書きます。届いたメールはその材料です。
- **開いているメールごとに会話が分かれます** — 別のメールを開いたり、別のウィンドウで返信したりしても、今開いていないメールの相手や文面を、その返事には使いません。ウィンドウを閉じても、そのメールについて保存した履歴は残ります。次に同じメールを開くと、その履歴を再び使います。
- **宛先と件名は確認してから変えます** — 宛先（To・Cc・Bcc）や件名を変えるときは、変える前と後を画面に出します。このメールのやり取りにいない人へ宛先を変えるときは、その旨を知らせます。「適用」を押すまでメールには何も書きません。「キャンセル」なら元のままです。
- **見えない文字や極端に小さい文字は外します** — 受け取ったメールにある、Word の隠し文字、1 ポイント以下の文字、白い地の白い文字、画面に出ない指定は、文面を考える材料から外します。
- **どの版を入れたか分かります** — インストーラーのファイル名と、画面の「ビルド」に、版の番号、ビルドの識別子、作った日時が出ます。
- **LAN の注意は閉じられます** — 「暗号化されていない LAN 宛」という注意は、一度閉じると、同じ URL のあいだは出ません。別の URL に変えると、また出ます。
- **保存してある API キー** — すでに API キーを保存してあるときは、起動したときに「未設定」とは出ません。

## できること

- **下書きと推敲** — 自由入力と、御礼・承諾・お断り・日程調整・邦訳・英訳のボタン
- **宛先と件名** — 宛先・件名の変更は確認してから適用します。やり取りに出てこない宛先へ変えるときは、その前に注意を出します
- **参考情報** — SearXNG、同一 PC の Argos 索引、送信済みメールの言い回し
- **予定表** — 空き時間と予定一覧。チャットで期間を指定すると、その期間の空きを返す。探す日数は 7〜60 日（既定 14）。Outlook に加え、設定した Google カレンダー（ICS）も読める
- **ファイル** — クリップ、ドラッグ＆ドロップ、開いているメールの添付。画像と文字の少ない PDF は LLM の画像読み取り。メールの添付は「OCR開始」を押したときだけ読む
- **履歴とメモ** — 会話の履歴と、いつも使うメモ、相手ごとのメモ。開いているメールごとに会話は分かれます

対応形式: PDF / テキスト / Markdown / 画像（PNG・JPEG・GIF・WebP） / Word（DOCX） / Excel（XLSX）

## インストール後の流れ

1. `{SETUP}` を実行する
2. Outlook を起動し、メールのリボンに **LexCrew** を開く
3. 設定で LLM の URL、API キー、モデル名を入れる
4. 画像やスキャン PDF を読むときは、画像に対応したモデルを選ぶ

入れ直しても、メール履歴（`%APPDATA%\KURU`）は残ります。
