Outlook クラシック（デスクトップ版）のメール画面で、ローカル LLM を使って返信の下書きや文面の推敲を行う Windows アプリです。作業ウィンドウに指示を書くと、開いているメールを読んで文面を整えます。メールの送信はしません。本文に入るのは、署名と引用の上に差し込む前文だけです。宛先と件名は、確認してから変えます。

## この版の変更

これはセキュリティのための更新です。機能と使い方は 1.2.0 から変わっていません。

- **画面に出す文字を整える DOMPurify を 3.4.17 に更新しました** — アドバイザリ GHSA-cg2g-xh64-v4q7、GHSA-mrv2-3pqr-j5jr、GHSA-c6gr-qvv4-5v3f への対応です。LexCrew-Mail の設定では、これらを悪用できませんでした。予防のための更新です。
- **同梱の Node.js は 22.23.4 のままです** — 1.2.0 と同じ版です。機能の追加や変更はありません。
- **64 ビット版だけです** — 対象は 1.2.0 と同じです。Windows 10 / 11（64bit）の、64 ビット版 Outlook クラシックです。

## できること

1.2.0 と同じです。インストーラに同梱する Node.js は 22.23.4 です。

- **下書きと推敲** — 自由入力と、御礼・承諾・お断り・日程調整・邦訳・英訳のボタン
- **要返信** — 受信トレイから、返信が要りそうなメールを一覧にする。既定は過去 3 日、最大 30 件
- **宛先と件名** — 宛先・件名の変更は確認してから適用します。やり取りに出てこない宛先へ変えるときは、その前に注意を出します
- **参考情報** — SearXNG、同一 PC の Argos 索引、送信済みメールの言い回し
- **予定表** — 空き時間と予定一覧。チャットで期間を指定すると、その期間の空きを返す。探す日数は 7〜60 日（既定 14）。Outlook に加え、設定した Google カレンダー（ICS）も読める
- **ファイル** — クリップ、ドラッグ＆ドロップ、開いているメールの添付。画像と文字の少ない PDF は LLM の画像読み取り。「メール添付ファイルを読む」がオンのとき（既定）、テキストは自動で読みます。メールの添付の画像と文字の少ない PDF は「OCR開始」を押したときだけ読みます
- **履歴とメモ** — 会話の履歴と、いつも使うメモ、相手ごとのメモ。開いているメールごとに会話は分かれます

対応形式: PDF / テキスト / Markdown / 画像（PNG・JPEG・GIF・WebP） / Word（DOCX） / Excel（XLSX）

## インストール後の流れ

1. `{SETUP}` を実行する
2. Outlook を起動し、メールのリボンに **LexCrew** を開く
3. 設定で LLM の URL、API キー、モデル名を入れる
4. 要返信で自分の名前を探すときは、設定の「自分の名前」に呼ばれ方を 1 行ずつ入れる
5. 画像やスキャン PDF を読むときは、画像に対応したモデルを選ぶ

入れ直しても、メール履歴（`%APPDATA%\KURU`）は残ります。`%LOCALAPPDATA%\KURU\tls` の証明書も残ります。
