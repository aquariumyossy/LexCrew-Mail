Outlook クラシック（デスクトップ版）のメール画面で、ローカル LLM を使って返信の下書きや文面の推敲を行う Windows アプリです。作業ウィンドウに指示を書くと、開いているメールを読んで文面を整えます。メールの送信はしません。本文に入るのは、署名と引用の上に差し込む前文だけです。宛先と件名は、確認してから変えます。

## この版の変更

- **要返信を探せます** — 作業ウィンドウの「要返信を探す」で、受信トレイから返信が要りそうなメールを一覧にします。チャットで「先週の〇〇さんからの未返信」のように頼んでも、同じ一覧が開きます。
- **拾うメールは二種類です** — 宛先が自分で、まだ返信していないメール。そして、設定した自分の名前（「吉田先生」「𠮷田先生」「吉田さん」「秀平」など）が件名か本文にあるメールです。メーリングリストも含まれます。吉と𠮷は同じ文字として探します。`>` で始まる引用行は数えません。Outlook の引用として除くのは、その行だけの `Original Message` / `元のメッセージ`（前後をハイフンで挟んだ行を含む）と、近くに `送信日時:` / `Sent:` / `Date:` がある `差出人:` / `From:` です。iPhone や Mac の日本語メールのように、`差出人:` の近くに `日付:` と `宛先:` または `件名:` があるときも引用です。文の途中の「差出人」や from:、「元のメッセージを残して」のような文、`差出人:` だけの文面、`差出人:` と `日付:` だけの文面は引用にしません。
- **探す範囲** — 既定は過去 3 日、最大 30 件です。日数は設定で変えられます。チャットで「14日分探して」や「今日の未返信」のように日数を指定したときは、長くても短くても「この検索だけ過去N日にします」とその検索だけに使い、設定は変えません。モデルが自分から範囲を広げるときは「もっと前のメールも探しましょうか？」と尋ねます。同意したあと保存するのは、その検索より長く、かつ設定より長い日数だけです。たとえば設定が 14 日で、今日だけ探したあとに 7 日へ広げるときは、その検索だけに使い、設定は 14 日のままです。同意は「もっと前のメールも探しましょうか？」の直後の返事全体が「はい」「お願いします」「お願いしますね」「お願いいたします」「よろしくお願いします」「探してください」「探して」「お願い」「うん」「OK」「yes」だけのときです。別の質問への「はい」は同意ではありません。添付が付いていても、判断はその返事だけです。「はい、必要ありません」や「やっぱりやめといて」は同意ではありません。尋ねた直後、返事の前に、その検索より長い日数を渡すと拒否します。日数を省略しても、設定がその検索より長いときは拒否します。一覧の「過去N日も探す」は、設定より長いときだけ保存します。LLM のアドレスなどは変えられません。
- **返信したかどうか** — Outlook の返信マークか、送信済みにある返信で判断します。送信済みの返信は、件名（Re: や [list 123] のような印を除いて）が一致し、宛先か CC に受信メールの差出人・Reply-To・メーリングリストのアドレスがあるものです。To や CC に入っていた同僚だけへの転送や返信では、返信済みにしません。電話から送って Outlook の送信済みに残らない返信は、要返信のまま残ります。
- **一覧の各行** — 件名、差出人、受信日時、要返信・要確認・不要の印、一行の理由です。名前だけが出てくるメールや、別の人へのメールは不要になります。判定には、各メールの短い抜粋だけを渡します。
- **メールを開く** — 「ジャンプ」で Outlook のメインウィンドウのそのメールを選びます。「別ウィンドウで開く」で、そのメールだけのウィンドウを開きます。
- **探すだけです** — 探すだけでは既読やフラグは変えません。移動も削除もしません。送信も転送もありません。一覧からメールを開くときは、普段メールを開いたときと同じです。
- **少ないときは、さらに前を聞く** — 要返信が少ないときは「もっと前のメールも探しましょうか？」と聞きます。件数や時間の上限で打ち切ったときは聞きません。同意したときだけ、その検索より長く、かつ設定より長い日数を保存します。設定を短くはしません。探しているあいだは進み具合と「止める」ボタンを出します。件数と時間に上限があり、Outlook が固まり続けないようにしています。

## できること

1.1.1 に加え、要返信の一覧が使えます。

- **下書きと推敲** — 自由入力と、御礼・承諾・お断り・日程調整・邦訳・英訳のボタン
- **要返信** — 受信トレイから、返信が要りそうなメールを一覧にする。既定は過去 3 日、最大 30 件
- **宛先と件名** — 宛先・件名の変更は確認してから適用します。やり取りに出てこない宛先へ変えるときは、その前に注意を出します
- **参考情報** — SearXNG、同一 PC の Argos 索引、送信済みメールの言い回し
- **予定表** — 空き時間と予定一覧。チャットで期間を指定すると、その期間の空きを返す。探す日数は 7〜60 日（既定 14）。Outlook に加え、設定した Google カレンダー（ICS）も読める
- **ファイル** — クリップ、ドラッグ＆ドロップ、開いているメールの添付。画像と文字の少ない PDF は LLM の画像読み取り。メールの添付は「OCR開始」を押したときだけ読む
- **履歴とメモ** — 会話の履歴と、いつも使うメモ、相手ごとのメモ。開いているメールごとに会話は分かれます

対応形式: PDF / テキスト / Markdown / 画像（PNG・JPEG・GIF・WebP） / Word（DOCX） / Excel（XLSX）

## インストール後の流れ

1. `{SETUP}` を実行する
2. Outlook を起動し、メールのリボンに **LexCrew** を開く
3. 設定で LLM の URL、API キー、モデル名を入れる
4. 要返信で自分の名前を探すときは、設定の「自分の名前」に呼ばれ方を 1 行ずつ入れる
5. 画像やスキャン PDF を読むときは、画像に対応したモデルを選ぶ

入れ直しても、メール履歴（`%APPDATA%\KURU`）は残ります。`%LOCALAPPDATA%\KURU\tls` の証明書も残ります。
