# LexCrew Mail

Outlook クラシック（デスクトップ版）のメール画面で、ローカル LLM を使って返信の下書きや文面の推敲を行う Windows アプリです。作業ウィンドウに指示を書くと、開いているメールを読んで文面を整えます。**メールの送信はしません。** 作成中のメールに入るのは、署名と引用の上に差し込む前文だけです。

## できること

### メールの下書きと推敲

- 自由入力で「返信の下書きを書いて」「この文面を短くして」などと指示できる
- **御礼・承諾・お断り・日程調整** のショートカットボタンで、よくある返信をすぐ作れる
- 閲覧中のメールには書き込まない。返信・転送など、作成ウィンドウを開いた状態で使う
- チャットに表示された文章はメール本文には入らない。モデルが書いた前文だけが Outlook に反映される

### 参考情報の利用

モデルは必要に応じて次の情報を参照します（設定でオン・オフや URL を指定）。

| 機能 | 説明 |
|------|------|
| **ウェブ検索** | SearXNG で公開ウェブを検索する |
| **Argos** | 同一 PC 上の Argos 索引（社内資料など）を検索する。作業ウィンドウで参照するフォルダを選べる |
| **過去メール** | 送信済み・受信トレイから、用件の語と相手のメールアドレスで過去の言い回しを探す |

### 予定表

- **空き時間** … 設定した対応時間・曜日・枠の長さに合わせて、連続して空いている時間帯を候補に出す（日程調整ショートカットと連動）
- **予定一覧** … 今日・今週・期間指定などで、件名と場所つきの予定を読む
- Outlook の予定に加え、設定した Google カレンダー（ICS）も読める

### ファイル

- 作業ウィンドウに **クリップで添付したファイル** の内容を読み、文面に活かせる
- 対応形式の例: PDF、テキスト／Markdown、画像、Word（.docx）、Excel（.xlsx）  
  画像やスキャン PDF は、設定した LLM の画像読み取り（OCR）を使う
- 設定でオンにすると、**開いているメールの添付** も読める

### 履歴とメモ

- **会話の履歴** … これまでのやり取りを保存し、別のスレッドに切り替えて再開できる
- **コンテキスト** … いつも使うメモと、相手ごとのメモを残せる（モデルへの system プロンプトに反映）

### その他の UI

- フォント（游ゴシックなど）とサイズを選び、差し込む前文に反映できる
- コンテキスト使用量のメーター表示
- 思考モード・ツール呼び出し回数などの詳細設定

## 動作のイメージ

```
Outlook（COM アドイン） ── window.kuru ──► 作業ウィンドウ（Web UI）
                                              │
                                              ▼
                                    ローカル sidecar（HTTPS :28770）
                                              │
                         ┌────────────────────┼────────────────────┐
                         ▼                    ▼                    ▼
                   ローカル LLM          SQLite 履歴           SearXNG / Argos
```

- Outlook 側の COM アドインが作業ウィンドウを開き、同梱の **トレイアプリ** が Node の sidecar を起動する
- メールの読み書き・予定・添付は Outlook API（C#）経由。LLM との通信と履歴 DB は sidecar（TypeScript）が担当する

## 動作環境

- **OS** … Windows 10 / 11（64bit）
- **Outlook** … 64 ビット版の Outlook クラシック（Microsoft 365 / 永続ライセンスなど）
- **WebView2** … 未インストールの場合はインストーラの案内に従って追加
- **LLM** … OpenAI 互換 API（例: ローカルの MTPLX など）。URL と API キーを設定画面で指定
- **任意** … SearXNG、Argos（ローカル索引）

管理者権限は不要です。現在のユーザー向けにインストールされます。

## インストール（利用者向け）

1. 配布物の `LexCrew-Mail-Setup-1.0.0.exe` を実行する（バージョンは配布物に合わせる）
2. 画面の指示に従う
3. Outlook を起動し、メールのリボンに **LexCrew** を開いて作業ウィンドウを表示する
4. 設定で LLM の URL・API キー・モデル名を入れる

メール履歴（`%APPDATA%\KURU`）は、アプリを入れ直しても残ります。接続設定は LexCrew 系アプリと共有する場合、`%APPDATA%\LexCrew\connection.json` に保存されます。

## 開発者向け

### 必要なもの

- Node.js（パッケージ作成時は 22 系でビルド）
- .NET Framework 4.x（Outlook アドインのコンパイル）
- Outlook 用 NuGet パッケージ（`outlook/packages`。初回は `package.ps1` 実行前に取得）

### コマンド

```bash
npm install
npm run dev-server    # 開発用 HTTPS + webpack（https://127.0.0.1:28770）
npm test              # Vitest
npm run build         # フロントを dist/ にビルド
npm run package       # release/ にインストーラ一式を生成（要 Windows）
```

### 主なディレクトリ

| パス | 内容 |
|------|------|
| `src/taskpane/` | 作業ウィンドウ UI |
| `src/sidecar/` | API・LLM プロキシ・履歴 DB |
| `src/shared/` | プロンプト・ツール定義・共有ロジック |
| `outlook/src/` | Outlook COM アドイン（C#） |
| `installer/` | インストール／アンインストールスクリプト、NSIS |
| `scripts/package.ps1` | リリース用の一括ビルド |

## 注意

- 生成された文面は **下書き** です。法律意見ではありません。送信前に内容を確認してください。
- 根拠としてモデルが参照できるのは、ウェブ検索結果、Argos で選んだ資料、予定の件名・場所、読み込んだファイル・メールの範囲に限られます。
- 本リポジトリのソースをビルドしただけでは Outlook に登録されません。`npm run package` で作ったインストーラから導入してください。

## ライセンス

本アプリの配布条件はリポジトリ管理者が別途定めます。実行時に同梱されるオープンソースライブラリの一覧とライセンスは、作業ウィンドウの「このアプリについて」にも記載しています。
